- 자동 할당 퍼블릭 IPv4와 Elastic IP는 구분합니다. Elastic IP를 만들지 않았다면 삭제했다고 쓰지 않고 미할당으로 기록합니다.
- EBS는 `Delete on termination`이 켜진 볼륨만 인스턴스 종료 시 자동 삭제됩니다. 기록한 볼륨 ID로 실제 목록을 확인합니다.
- Terminated 인스턴스가 잠시 목록에 표시되어도 실행 중인 리소스는 아닙니다.
- VPC의 기본 SG·기본 Route Table·기본 Network ACL은 VPC 삭제 시 함께 제거됩니다.
- 공유·기존 리소스는 이번 실습 대상에서 제외합니다.
